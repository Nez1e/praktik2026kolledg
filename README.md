# praktik2026kolledg
**Колледж заданий** — учебный проект по предметной области "AccessEvent".

## О проекте
AccessEvent — это платформа для организации мероприятий с акцентом на доступность для людей с нарушениями слуха. 
Проект разрабатывается в рамках учебной практики.

## Структура репозитория
* `.github/workflows` — файлы CI/CD для автоматизации проверок.
* `docs` — документация проекта (анализ предметной области, схемы).
* `src` — исходный код приложения.
* `tests` — тесты для проверки работоспособности кода.
